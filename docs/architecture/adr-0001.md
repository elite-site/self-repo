# ADR-0001 — Student identity is Google Workspace SSO, SSO-only

## Status

Accepted. Decided 2026-09-20.

## Context

The portal replaces a password-based roster that was weak and brittle to maintain:
passwords were shared, rotated ad hoc, and had no recovery path. The institution
runs Google Workspace on `sasi.ac.in`, so every student and staff member already
has a managed identity we can trust without building a credential store. Emails
are the only stable, human-meaningful key we hold for students.

## Decision

Authentication is OAuth 2.0 with Google Workspace, and SSO-only: no rollNo/password
fallback, no local password table. The flow is the standard `oauth2client` authorize
+ callback exchange implemented in `backend/src/services/sso.service.ts`, verifying
the returned `id_token` server-side and restricting logins to the college domain.
The email from the roster import is the only allowlist; a login only succeeds when
the verified Google email matches a roster email.

Alternatives considered: password + one-time-password (OTP) via Resend, rejected
because it introduces an email-deliverability dependency for the critical path;
keeping the password roster, rejected as the weak status quo.

## Consequences

- 26 students with empty emails in the roster are locked out until their emails are
  supplied and the roster is re-imported.
- An external dependency is open: a Google OAuth client (with callback URL and the
  college domain as authorized origin) must be approved in the college's Google
  Cloud console before production student login works. Tracked in the implementation
  plan; cannot be unblocked by this repo alone.
- No password hashing, reset, or credential compromise surface to maintain.
- Roster email changes require a re-import before the student can log in again.
- The OAuth `state` is a stateless, server-signed 10-minute JWT (not bound to a
  cookie); this accepts a low login-CSRF risk (an attacker must already be a
  roster-registered student) and should be revisited before higher-risk deployments.
